# Tetromancy

A two-player, wizard-themed Tetris you play on one keyboard, one screen.
No server, no build step, no dependencies — it's a single HTML file.

## How to play

Just open `index.html` in a browser. That's it.

Or host it for free with GitHub Pages: push this repo to GitHub, go to
**Settings → Pages**, set the source to the `main` branch / root folder, and
your game is live at `https://<your-username>.github.io/<repo-name>/`.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | ← / → |
| Soft drop | S | ↓ |
| Rotate | W | ↑ |
| Hard drop | Space | Enter |

First wizard to stack blocks to the top of their board loses. Click
**Play Again** to reset both boards.

## What's in the box

Real Tetris mechanics, not a toy: seven-bag piece randomizer (no unlucky
streaks of the same piece), proper rotation, line clearing, scoring that
scales with level, and increasing drop speed as you clear lines. Both
boards run independently side by side on the same page.
